// about the project

A Linux distribution
built for the community.

Abéllha OS is an open-source project — like any Linux distribution — developed on a non-profit basis and freely available to everyone. The goal is to offer a solid, customizable, and accessible foundation for anyone who wants to explore, modify, and contribute.

Strictly Prohibited Use

Commercialization, unauthorized copying, or claiming ownership of this project are strictly prohibited. Abéllha OS is a community-driven, non-commercial project — any violation of these guidelines directly breaches the terms of the GNU GPLv3 license.

// your freedoms

What you can do
with Abéllha OS.

Abéllha OS was built on the principles of free software. You have real freedom — not just to use it, but to actively participate in the project and the community.

Create derivative distributions

You have total freedom to create your own Linux distribution based on Abéllha OS, with modifications and customizations of your choice.

Create and publish an ISO

The project does not have an official ISO file. If you want to make the system easier to access, you can generate and publish an Abéllha OS ISO yourself.

Study and modify the code

All source code is available. Explore, modify, improve — and share your contributions with the community.

// ISO submission

Created an ISO?
We'd love to know.

If you create an Abéllha OS ISO file, send it to us — we will evaluate it and give you feedback. We cannot publish your ISO on your behalf, but you are free to publish it yourself. If you want to authorize us to publish it as well, we would be very grateful.

1

Create your ISO

Generate an installable ISO file based on Abéllha OS, with default settings or your own custom configurations.

2

Send it to us

Forward it to our email or through the GitHub inbox. We will review it and provide feedback regarding its quality.

3

Publish with freedom

You can publish your ISO freely. If you authorize us to publish it too, we are very grateful for your contribution to the community.
